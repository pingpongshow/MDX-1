Corrections from this check

  • PC13 is WKUP4 on this device (PA0 is WKUP1, PA2 is WKUP2). The standby wake-up constant in hal_stm32.c is now PWR_WAKEUP_PIN4_LOW.
  • PA9 doubles as the USB VBUS sense input. It is used as USART1_TX, so the USB stack must run with VBUS sensing disabled (already the configuration in the target code).
  • PC9 (MCO2 to the ADCs) is also SDMMC1_D1; the SD card therefore runs in 1-bit mode, which the pin map already assumed.

What CubeMX would add

When the project is opened in CubeMX, the remaining things to confirm are the clock tree (PLL1 N = 56 from a 16.384 MHz HSE, PLL2 for the 32.768 MHz SAI kernel clock), the DMA stream assignments used in the target code (DMA1 streams 0–2) and the SAI1 block B TDM settings. None of those are pin questions.

How to read these numbers

  • The board-only figure answers "what does it cost to build the PCB": about $505.47 for the first assembled board, falling to $389.47 each for five and $178.58 at a hundred.
  • Quantity-1 unit prices are taken from the actual DigiKey, Mouser and Coilcraft shopping carts (September 2026); six parts not in those carts (fuel gauge, 16.384 MHz crystal, coil header, JST 2-pin) keep a catalogue-typical estimate. The quantity-100 column is a volume estimate, not a quote. Re-price against a live quote before ordering.
  • Buying qty-1 passives means bags of 10–100, which adds roughly $30–50 to a first build beyond the attrition line.
  • The two most expensive board components are the two ADCs and the MCU; the display is the most expensive single part overall. There is no realistic saving on the ADC without giving up the design's main advantage.
